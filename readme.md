Set-Up:

1) Install Node.js from https://nodejs.org/en/download
Ensure there is a valid path, it will look in: C:\Program Files\nodejs\node.exe
Change line 55 if needed

2) Install FFmpeg from https://www.ffmpeg.org/download.html or get build from https://www.gyan.dev/ffmpeg/builds/
Ensure there is a valid path

3) Go to your browser install Get cookies.txt LOCALLY https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc
Go to Youtube->Extensions->Get cookie.txt LOCALLY->Export
Save the file as cookies.txt and place it in \ytDownloader\

If all steps are followed and paths are made program shoudl work without problem
if not user issue ¯\_(ツ)_/¯

Outputs will go their folder (audio to audio_outputs, videos to video_outputs)

**Note you need both the yt_dlp and customtkinkers python libraries for it too run :)
